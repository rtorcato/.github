# Security Policy

## Supported Versions

Only the latest release of each package receives security fixes.

## Reporting a Vulnerability

Please don't open a public issue for a security vulnerability. Report it privately using either:

- GitHub's **Report a vulnerability** button on the affected repository's Security tab, or
- Email to [reports@torcato.dev](mailto:reports@torcato.dev).

Include the affected package and version, the steps to reproduce, and the impact you expect.
